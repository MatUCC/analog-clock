# Analog Clock

A Python desktop analog clock built with the standard library only.

## Features
- Live analog clock with hour, minute, and second hands
- Digital date and time display
- Stopwatch with start, pause, and reset
- Light and dark themes
- Object-oriented implementation

## Requirements
- Python 3.9 or newer recommended
- Tkinter (usually included with standard Python installations)

No third-party packages are required.

## Run
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Run `main.py` with Python, or use a terminal:

   ```bash
   python main.py
   ```

On some systems, use `py main.py` instead. If Python was installed without Tkinter, install a Python distribution that includes Tk support.
